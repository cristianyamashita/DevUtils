# Dev Utils

## Description

A collection of utilities for developers, including a CLI tool and a web interface. The project is designed to be modular and extensible, allowing for easy addition of new features and tools.

## Usage

### setup-ai-rules.sh
Add common AI rules to a repository by running:
```bash
./setup-ai-rules.sh /path/to/repository
```
